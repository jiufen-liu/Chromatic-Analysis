Chromatic Analysis v0.14.6 UI Studio MDI Preview 1

目标
- 只优化 UI / 窗口承载方式，不修改色彩算法、解析、数据库、导入导出和既有业务逻辑。
- 视觉严格向 Light Studio 参考图靠拢：冷灰背景、白色表面、唯一蓝色强调、统一圆角/边框/间距。
- 修复“打开比色工作台会替换/关闭正式色库”的视觉容器问题：正式色库、比色工作台、查色、色卡编排、光谱分析现在各自拥有独立的 QMdiSubWindow，可以同时存在、移动、最小化、最大化、还原和关闭/重新打开。

本次 UI 变更
1. 顶部品牌栏：56px 白底 + 分隔线，品牌、版本、菜单、搜索、头像/账号统一成参考图比例。
2. 左侧导航：218px #F9FAFB，蓝色“打开文件”主按钮，工作区/本地文件分组，底部拖入文件区域。
3. 主工作区：冷灰 #F3F4F6 MDI 画布；空白时仅显示轻量提示，不占用业务页。
4. 工具页：正式色库、比色工作台、查色/找色、色卡编排、光谱分析均复用原有页面对象，只改变其父容器为独立 QMdiSubWindow。
5. MDI 子窗口：支持原生最小化、最大化/还原、关闭、移动、Resize；关闭仅隐藏成熟页面，重新打开继续使用同一页面实例。
6. 色库：继续使用固定统一卡片 + 分页，业务选择/排序/右键/导入导出逻辑不变。
7. 比色表格：仅改视觉令牌，Standard 行从旧黄色高亮改为浅蓝选中语义，超差仍为红色文字。
