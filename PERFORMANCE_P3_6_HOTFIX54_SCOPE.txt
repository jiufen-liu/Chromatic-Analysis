Hotfix54 scope
1. Keep Datacolor QTX parsing grammar and field precedence unchanged.
2. Keep embedded Datacolor XYZ/Lab authoritative exactly as before.
3. For spectrum-only samples sharing one wavelength grid, group them and use
   colour-science MultiSpectralDistributions + ASTM E308 once per group instead
   of constructing/calculating one SpectralDistribution per sample.
4. Batch Lab conversion is vectorized after batch XYZ conversion.
5. Before accepting a batch group, first/middle/last spectra are compared with
   the pre-existing scalar reference path at very tight numerical tolerance.
6. If batch construction, colour-science API, wavelength grid, or numerical
   verification fails, automatically fall back to the old scalar algorithm.
7. CHROMATIC_DISABLE_QTX_BATCH=1 can force the old scalar path for diagnostics.
8. Performance baseline output now shows batch/scalar counts, fallback groups,
   block parsing time, sample preparation time, and colour-science time.
