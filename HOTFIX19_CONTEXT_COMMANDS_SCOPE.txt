Hotfix19 · Windows 右键与键盘操作整理（以 Hotfix18 为基线）

1. 色卡编排：Ctrl+A/C/X/V/Z/Y/S、Ctrl+Shift+S、Ctrl+E、Delete 使用同一组方案命令；网格与主程序仅负责把按键路由到当前方案。全选采用网格原生选择，必要时补齐选择模型，目标包含整个方案、排除空位。右键已选色卡保留多选；空位提供粘贴、添加与空位编辑；方案空白区域／方案窗口提供保存、另存为、导出、排序、网格及管理操作。保留光谱排序、555、2D/3D、荧光标记等既有能力。
2. 色库：色卡右键保留详情、查色、复制、收藏、加入方案/工作台、分析。复制使用原有色卡 MIME 类型，跨方案粘贴读取系统剪贴板。显示条件继续使用色库筛选控件。当色卡区域有键盘焦点时，Ctrl+A 以当前筛选的完整结果为范围，包括非当前页；文件列表和文本输入保留各自的快捷键。Delete 从当前视图隐藏；永久删除使用管理员右键明确命令和确认。客户标签的关闭、收起向普通使用者开放；管理 QTX 仍仅管理者可用。
3. 查色结果：原有选择范围、与标准比较、移除当前结果、2D/3D 和导出入口保留。
4. 比色工作台：表格 Ctrl+A、Ctrl+C 和 Delete 与表格右键操作一致。Ctrl+C 将可见列的选中行复制成制表符分隔文本；表头右键只管理列，阈值和 555 设置进入数据行的分析菜单。
5. 个人工作文件：色卡右键管理详情、查色、复制/剪切/粘贴、移除、分析；文件导入、保存、导出、排序和网格设置归入空白区域的右键菜单，色库写入仍仅管理者可用。
6. 菜单和快捷键保留原有权限处理，未修改测量数据、色差算法、文件格式和数据库结构。

验证：已对源码及测试代码执行 Python compileall，并检查关键类与命令存在。当前交付环境未安装 PySide6，无法运行 Qt 自动化测试或 Windows 图形界面实测。Windows 上重点按 tests/test_ui_selection_scope.py 验证两个方案之间的焦点隔离、79 色卡全选/复制，以及色库分页全选和普通使用者删除边界。
