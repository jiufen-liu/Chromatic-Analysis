# Chromatic Analysis v0.11.1 · Textile Spectral Studio

本版在 v0.11.0 全部功能上修正生产 QTX 与 ChromaShare 555 工作流。

## 本次核心修正

- 兼容 `[STANDARD_DATA 0],`、`[BATCH_DATA],` 等 section 尾部逗号。
- 同一文件可保留 400–700 nm / 31 点与 360–700 nm / 35 点等原始光谱网格；需要计算时再按共同范围插值。
- 比色工作台增加明确的 QTX 点击/拖入区域，支持多选文件和整个文件夹。
- 第一个导入的真实色样默认成为标准；不再自动建立平均标准。
- 只有主动点击“设为平均标准”才生成平均标准，后续新增色样也不会偷偷重算。
- 555 改为中心格容差模型：输入的 ±数值定义第 5 格，相邻完整格宽为 2 × 容差。
- 支持 `ΔL*/ΔC*/ΔH*` 与 `ΔL*/Δa*/Δb*` 两种分选空间。
- 支持直接粘贴 ChromaShare 四参数，例如 `0.45 + 0.45 + 1.26 + 0.63`。
- 第一项保存为整体 `ΔE*ab` 评价容差，后三项保存为三个 555 中心格容差。
- v0.11.0 保存的旧 555 参数不会自动套入新算法，必须重新确认。

## 555 定义

以 ΔL* 容差 0.45 为例：

- 第 5 格：`-0.45 ≤ ΔL* < +0.45`
- 第 4 格：`-1.35 ≤ ΔL* < -0.45`
- 第 6 格：`+0.45 ≤ ΔL* < +1.35`
- 相邻完整格宽：`0.90`

ChromaShare 参数 `0.45 + 0.45 + 1.26 + 0.63` 会拆成：

- 整体评价容差：`ΔE*ab = 0.45`
- 555 中心格：`ΔL* = ±0.45`、`ΔC* = ±1.26`、`ΔH* = ±0.63`

## 安装

Windows 下先双击 `安装依赖.bat`，完成后双击 `启动程序.bat`。也可在 PyCharm 中运行 `main.py`。
