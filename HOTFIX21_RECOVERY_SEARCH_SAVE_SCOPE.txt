Hotfix21 · 缺失色样、选中状态、当前文件搜索与保存副本

1. 色卡方案加载时根据完整内部编号精确比对已存色库及其他方案嵌入色样，若唯一匹配则保存完整快照到本方案并恢复色块/LAB。不同内容共用编号时不自动猜测。右键缺失卡可选择原始 QTX 恢复，只有编号确切一致才接入；源数据都不存在时需用户提供原文件。
2. 色卡编排选中的卡以高亮蓝色框及颜色块边缘显示，底部提供选中数量和悬停时的选中名称列表。
3. QTX/CPX/Excel 文档新增当前文件名称、编号和 LAB 搜索，隐藏非匹配项而不更改源数据；显示总数及选中数。
4. 管理员保存现有色库文件直接更新原记录；新文件首次保存创建记录；另存为独立副本先输入名称再选择目标库。普通用户继续仅能保存自己的 .chromatic 工作文件；导出仅产生交换文件。

验证：全部 Python 源码编译通过；精确恢复与冲突编号不自动覆盖的定向逻辑检查通过。当前执行环境无 PySide6，需在 Windows 上检验界面交互；没有数据库/原 QTX 的老旧缺失记录无法从截图重建测量数据。
