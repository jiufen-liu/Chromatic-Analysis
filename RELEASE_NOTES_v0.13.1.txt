Chromatic Analysis v0.13.1 · Color Studio Polish

1. 主界面轻量化
   - 移除主工具栏常驻光源/观察者、查色、比色、正式色库等按钮。
   - 只保留“＋打开”下拉入口和角色状态。
   - Ctrl+1/2/3/4 打开查色/比色/色卡/光谱工具。

2. 电子色卡视觉重做
   - 大色块 + 单行名称 + 柔和白色卡纸风格。
   - 圆角、轻边框、轻阴影、暖中性工作区背景。
   - 原始测量数据不变，只优化屏幕/Excel 的视觉预览。
   - 新的色域映射避免 RGB 通道硬裁切，超色域时保持 L/h 并压缩 C。

3. 色卡编排键鼠操作补齐
   - Ctrl+A 全选。
   - Ctrl+C/X/V、Ctrl+Z/Y、Delete、Esc、Ctrl+S。
   - 右键菜单继续提供同样操作。

4. 色卡/文档 3D
   - Ctrl+Alt+3 或右键“查看 3D 色彩空间”。
   - 有选择时显示选择项；无选择时显示当前色卡/文档全部色样。

5. 3D 参考云
   - 只列出正式色库里的客户。
   - 不再列出“全部色库”及每一个 QTX。
   - 选择客户后再按需加载该客户数据。

6. Excel 色卡
   - Color Card 使用与 UI 一致的预览色域映射。
   - 主色块更大、信息更克制；完整 Color Data / Reflectance / Attributes / Measurement Info 仍保留。

7. 其它
   - Datacolor 555、RBAC、客户本地数据、QTX/CPX/Excel 解析逻辑未重写。
