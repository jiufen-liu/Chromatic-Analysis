Chromatic Analysis v0.14.6.4 · Hotfix14

本次交付
1. 主导航仅保留“色库、工具”；比色工作台、查色、色卡编排及光谱分析归入“工具”。右键桌面空白处新建文件窗口，不显示工作区文件夹入口。
2. 新建文件窗口和直接打开 QTX / CPX / Excel 均使用统一的 WorkspaceDocument。文件窗口中右键“文件”可添加 QTX / CPX / Excel、保存个人工作文件、另存为、导出；也支持将文件拖入色卡区域。
3. Ctrl+S 保存 .chromatic 个人工作文件，Ctrl+Shift+S 另存为。此格式保存色样及原始属性、卡位（包括空位）、布局、标准和原始来源信息；原始 QTX/CPX/Excel 不会被覆盖。最近打开和左侧入口可重新打开该格式。
4. 管理员在右键“文件 → 存入色库”选择正式色库或官方色库；普通用户仍可保存个人工作文件。官方色库按“官方色库/分类”存储，左侧分类可直接打开，更多分类位于“更多…”。
5. 色卡编排和文件窗口的卡片选区均明确处理 Ctrl 点击、Shift 范围选择、Ctrl+A；同时处理 Qt 的快捷键抢占。卡片保留“名称 + Lab 数值”显示。
6. 左侧导航文件格式和官方色库改为统一尺寸的彩色图标，收藏及常用色库原有可添加和移除功能保留。
7. 荧光色预览沿用 Hotfix13 中按样品数据统一判定的显示算法，不绑定某个 QTX 文件。

已验证：Python 编译检查；.chromatic 写入、重开、原始数据和空卡位的往返检查。
当前运行环境缺少 PySide6，未执行 Windows 图形界面的现场点击验证。建议在 Windows 上重点检查两个色卡窗口中的 Ctrl 多选、Ctrl+A，以及 QTX / CPX / Excel 拖入和工作文件重开。
