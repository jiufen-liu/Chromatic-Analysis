# DG-3 scope

DG-3 adds personal ownership, managed local storage, backup/recovery and expanded auditing while preserving all validated P3 and DG-2 behavior.

- Personal: new comparison workbenches and color-card schemes are tied to the signed-in application user.
- Compatibility: old unowned records remain visible as legacy shared data so upgrades do not silently hide existing work.
- Managed storage: application-generated library mirrors and default personal work files live under application AppData rather than the project/program folder.
- Backup: daily snapshot + manual backup/restore console.
- Audit: login/admin actions plus personal work-file and export events.
- Library UI: current official/formal scope drives header/meta state consistently.
