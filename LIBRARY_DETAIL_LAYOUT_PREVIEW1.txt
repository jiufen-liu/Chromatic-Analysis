Chromatic Analysis v0.14.6.3 Library & Detail Layout Preview 1

本预览版仅优化用户指定的界面与窗口交互：

1. 颜色明细统一为同一套现代卡片界面，改为可最小化、可缩放的非模态窗口。
2. 明细底部增加明确的 2D / 3D 色彩空间入口；打开图形后不会被模态明细强制压在后面。
3. 正式色库、查色结果、色卡方案、临时工作区和工作台均调用同一个明细窗口。
4. 色库顶部改为搜索、分类、色系、排序下拉筛选；左侧增加客户 / QTX 搜索。
5. 色卡根据可用宽高自动计算列数、卡宽和每页容量，当前页铺满后才进入下一页。
6. 正式色库与比色工作台同时打开时首次自动排成左主右辅双栏；MDI 最小化不再留下突兀标题条。

未改动 QTX / CPX / Excel 解析、色差算法、555、光谱、数据库、导入导出、权限或正式色库写入规则。
