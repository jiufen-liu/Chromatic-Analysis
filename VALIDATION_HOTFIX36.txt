Architecture checks
-------------------
- RHI backend is not forced. Windows can use Qt's normal D3D11 path.
- 3D sample coordinates are uploaded once through FileInstancing.
- Camera rotation is handled in QML/Qt Quick rather than a Python per-sample paint loop.
- Same-window CPU projection is retained only as an emergency compatibility path.
- Derived gamut surface is presentation-only and does not modify sample Lab values.

Runtime validation limitation
-----------------------------
The build environment used to prepare this hotfix does not contain PySide6 and
has no Windows D3D11 desktop. Therefore a real Qt Quick 3D/RHI frame cannot be
executed here. The first full runtime validation must be performed on Windows.
The project includes RUN_3D_SOFTWARE_FALLBACK.bat for machines where hardware
RHI initialization is unavailable.
