Runtime limitation in this build environment
--------------------------------------------
PySide6 and colour-science are not installed in the current build container, so the full GUI and numerical colour-difference runtime were not launched here. The project already depends on those packages in the user's Windows environment. No claim is made that GUI interaction was exercised in this container.

Behaviour contract
------------------
LABCH:
- L*/a*/b*/C*: keep the established first-click descending behaviour, repeat click reverses.
- h°: first click sorts 0° -> 360°, repeat click reverses.

Color Difference:
- exactly one selected colour is required;
- follows MainWindow.active_formula (CIEDE2000 / CIE94 / ΔE*ab / CMC 2:1);
- sorts all occupied palette samples from nearest to farthest from the selected reference.

Running ΔE:
- exactly one selected colour is required as start;
- greedily chooses the minimum ΔE remaining sample under the current formula;
- deterministic tie-break = original palette order, then stable sample key;
- runs in background;
- >1500 samples are blocked with an explanatory message to avoid O(N^2) GUI/performance risk.

LABC Atlas:
- remains the ongoing professional atlas inspired by the Munsell-style organisation approach;
- no separate Munsell sorter has been added.
