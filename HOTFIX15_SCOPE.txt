Chromatic Analysis v0.14.6.4 · Hotfix15
基于 Hotfix14 的增量修订。

1. 顶部品牌区域设定固定宽度，“色库 / 工具”紧随品牌靠左排列。
2. 管理者的“用户与权限”增加“功能权限…”：可分别控制普通账户查看色库、查色、比色、色卡编排、光谱分析、导出、保存个人工作文件。权限按账户写入原有本机认证数据库，老账户默认保持现有功能；管理者保留全部管理权限，正式和官方色库写入仍限管理者。
3. 文件窗口右键菜单“文件 → 导出 → QTX / CPX / Excel 色卡”作为贴近当前右键菜单的原生子菜单，不再从窗口右上角弹出。
4. 色库全选取当前客户或全部客户下“全部符合当前搜索/分类/色系条件的色卡”，跨所有分页；只渲染当前页色卡，翻页仍保留选中状态。
5. 色库左侧新增“正式色库 / 官方色库”切换；官方色库仅显示“官方色库/分类”记录，正式色库不混入官方记录。既有文件导入方式和管理员写入权限沿用。
6. 色卡编排 Ctrl 点击、Shift 连续选择和 Ctrl+A 改为明确更新 Qt 的选区模型；空槽不会被纳入全选，并在状态栏显示被选中的真实色卡数量。快捷键同时识别系统标准键和 Ctrl+A 原始按键。

已验证：全项目 Python 编译检查，原有账户数据库迁移及逐项权限检查，80 个色库色卡分 32 张/页时跨页全选的逻辑检查，80 个编排槽位（含 20 空位）选择 60 张实卡的选区模型模拟检查。
限制：当前环境未提供 PySide6 / Windows 图形桌面，未进行 GUI 点击现场测试；安装后建议用 79 色样方案检查 Ctrl 多选与 Ctrl+A 是否显示全部蓝色选框。
