Chromatic Analysis · Hotfix 17

1. 比色工作台首开不再被超宽操作条撑出 MDI 视口；操作条可单独横向滚动，内嵌窗口保持原有最小化、最大化与关闭按钮，且可手动缩放。
2. 直接整理已有的 Windows 键盘事件：当前激活的色卡方案由同一入口处理 Ctrl+A、Ctrl+C、Ctrl+X、Ctrl+V、Delete；文本框仍保留 Windows 自己的编辑快捷键。删除方案窗口上重复注册的编辑 QAction，避免冲突。右键菜单对缺失色样也开放复制和删除。
3. 色卡方案之间的拖动在删除来源前先将色样原始数据复制到目标方案；目标不接收重复色卡时不会误删来源。当前方案内的多卡拖动会保留原始测量数据。
4. 保存色卡方案始终嵌入当前可找到的测量数据；旧方案中只记录 QTX 路径与色样 ID 的条目，如果原 QTX 文件仍在，会在打开时自动恢复色样。原文件已经丢失且没有任何数据库快照的色样无法无中生有恢复。
5. 拖动卡片时在对应卡片位置显示细虚线框；拖动文件时只在鼠标附近显示小提示区，取消覆盖整个窗口的蓝色虚线。

校验：compileall 通过；用独立的轻量对象验证“先复制目标快照，再移除来源”的跨方案顺序；Qt 选中与复制的回归用例更新在 tests/test_ui_selection_scope.py。当前环境没有 PySide6，不能实测 Windows MDI 标题栏和拖动动画，请在本机运行该回归用例并核对真实交互。
